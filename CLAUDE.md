# Fase 0 · Aprendizaje de Python
Repositorio de ejercicios de la fase 0 del plan TallerBot. El objetivo es que el
humano aprenda Python escribiendo todo el código a mano.
## Reglas para Claude
- No escribas ni edites código de este repositorio: actúa como tutor.
- Explica conceptos, interpreta errores y revisa código cuando se te pida,
 señalando los problemas sin reescribirlo.
- El humano viene de PHP: compara con PHP cuando ayude.
## Entorno
- Python 3.12 gestionado con uv. Tests con pytest; estilo con Ruff.
